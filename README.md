# Sena Kim — Portfolio Site

A responsive, single-page portfolio prepared for GitHub Pages. The site is a single `index.html` file with its CSS and JavaScript included, so it does not need a build step or external dependencies.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create or open the GitHub repository for the portfolio.
2. Add `index.html` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the branch containing `index.html` and the `/ (root)` folder, then save.

## Before publishing

- Review all dates, project descriptions, and metrics against the final resume.
- Add a resume PDF if desired and link it from the page.
- Add any additional public contact details you want employers to see.
- Replace the LinkedIn URL if the public profile URL changes.
